# GW Observer

A Guild Wars 1 GvG match replay and analysis tool.

GW Observer lets you load and replay recorded GvG
matches in a 3D map view, with full player tracking,
skill cast timelines, combat analysis, and tactical
overlays.

---

## Features

- 3D terrain rendering using your local Guild Wars
  DAT file
- Agent cylinders with team color coding
- Skill cast bars and combat log
- Event timeline with team health curves
- Range rings and fog of war overlays
- Morale tracking
- Auto camera with configurable focus logic
- Match data integration via Tolkano.com

---

## Requirements

- Windows 10 or later
- A valid Guild Wars installation (Gw.dat required)
- DirectX 11 capable GPU

---

## Getting Started

1. Download the latest release from the Releases page
2. Run GWObserver.exe
3. On first launch, accept the licence agreement
4. Point GW Observer to your Gw.dat file
5. Load a match from the match browser

> **Note:** GW Observer cannot share the DAT file with
> a running Guild Wars instance. If you want to run
> both simultaneously, copy your Guild Wars folder
> to a separate location and point GW Observer to
> the copy. See the first launch screen for details.
